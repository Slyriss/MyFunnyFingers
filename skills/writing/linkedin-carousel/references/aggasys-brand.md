## Colour palette

| Name | Hex | Usage |
|---|---|---|
| Navy (primary) | `#0D2B55` | Cover bg, headings, table headers, section dividers |
| Cyan (action) | `#00AEEF` | CTAs, rule lines, callout borders, active/hover — NEVER for body text |
| Charcoal | `#1A1A2E` | All body copy — never pure black |
| White | `#FFFFFF` | Content slide backgrounds, reversed text on dark |
| Mid Gray | `#6B7280` | Captions, footnotes, secondary labels |
| Light Gray | `#F3F4F6` | Panel backgrounds, alternating rows |
| Success Green | `#16A34A` | Inclusion ✓ symbols only |
| Alert Orange | `#F59E0B` | Warning ⚠ callouts only |
| Error Red | `#DC2626` | Exclusion ✗ symbols only |

**Rules:**
- Navy is dominant — use for all primary headings and cover slides
- Cyan is the one action colour — never use decoratively or for body text
- Never place navy text on a dark background — reverse to white
- **No gradients** — Aggasys aesthetic is flat and clean
- Never introduce unauthorised colours (purple, yellow, pink, orange as brand colours)

## Typography

**One typeface only: Arial** (Helvetica / system sans-serif as fallback).
No serif fonts, no decorative fonts, no display fonts.
Courier New/monospace for technical strings only (IP addresses, firmware versions, hex codes).

| Role | Size | Weight | Colour |
|---|---|---|---|
| Slide hook headline | 56–64pt equiv | Bold | White (on navy) |
| Sub-hook / subtitle | 28–32pt equiv | Regular | Cyan (on navy) |
| Content heading (h2) | 40–48pt equiv | Bold | Navy (on white slides) |
| Body / bullet | 18–22pt equiv | Regular | Charcoal |
| Caption / label | 14–16pt equiv | Regular | Mid Gray |
| Kicker / label | 22–26pt equiv | Bold | Navy or Cyan |

**Rules:**
- Never more than two type sizes on a single slide
- **Sentence case** for all headings — not ALL CAPS (except logo lockup)
- Body text: left-aligned. Centre-align only for cover slides and hero statistics
- Italic for emphasis within body copy only — never for headings
- Bold for labels, key phrases, table headers — not whole paragraphs

## Carousel specifications (Section 7)

**Canvas:** 1080×1080 px square or 1080×1350 px portrait (4:5)
**Slides:** 4–8 per carousel (never fewer than 4)
**Headline limit:** max 15 words per slide
**Body limit:** max 40 words per slide
**Logo:** Aggasys logo on Frame 1 (bottom-left) and Frame N (CTA slide)

### Slide architecture

| Frame | Purpose | Design |
|---|---|---|
| Frame 1 — Hook | Stop the scroll. One powerful stat, metric, or bold question. | Navy bg (`#0D2B55`), white/cyan type. Aggasys logo bottom-left. |
| Frames 2–(N-2) — Content | One point per frame, build the narrative | White bg, navy heading, charcoal body. Icon/illustration in right column if used. |
| Frame N-1 — Proof | Case study stat or verified metric | Cyan accent bg (`#00AEEF`), navy/white text. Large centred stat. |
| Frame N — CTA | Drive action | Navy bg. "Get in touch" + aggasys.com + presales@aggasys.com. White text. |

## Hook formulas for Aggasys

Always lead with a **verified metric or proof point** — not the company name or tagline.

Good Aggasys hook patterns:
- Metric + sector: "50 servers. 400 GPUs. Zero downtime." (deployment proof)
- Proof point + promise: "1,000+ deployments. Here's what we learned."
- Problem + credential: "Most IT infrastructure fails silently. Here's how certified engineers prevent it."
- Sector stat: "360 schools. 400,000+ students. One infrastructure partner."

Never open with: "At Aggasys Solutions…" / "We are proud to…" / "World-class IT…"

## Voice rules for Aggasys carousels

- **British English**: authorised, customised, organisation (not authorized/customized/organization)
- **Active voice**: "Our engineers configure…" not "Configuration is performed by…"
- **Lead with specifics**: name the product, the number, the sector
- **Banned words**: world-class, best-in-class, cutting-edge, leverage, synergy
- **Preferred**: enterprise-grade, certified, proven, precision, seamless
- Spell out one–nine; numerals for 10+; always numerals for tech specs ("2U rack", "24 ports")
- No full stops at end of bullet items (unless full sentences)
- Authoritative, not arrogant — state facts with evidence, no hedging on technical claims

## Social media content rules (Section 7.3)

- Lead every carousel with a metric or proof point — not a company name or tagline
- Max 15 words per slide headline, max 40 words per slide body
- Every carousel must end with a CTA frame: aggasys.com and/or presales@aggasys.com
- All metrics must be verified before publication
- Never use personal photographs of clients without written consent
- Use real deployment photography where available (data centres, rack-mounted servers, cabling)
- No generic stock photos (handshakes, lightbulbs, "business people pointing at screens")
- No 3D illustrations or skeuomorphic imagery
- Line icons only: 2px stroke, navy for features, cyan for actions
